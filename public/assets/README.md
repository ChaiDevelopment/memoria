# Aset MEMORA

Semua aset 3D, tekstur, langit dan audio MEMORA, dikelompokkan per tema.

| Folder | Isi |
|---|---|
| `characters/` | Karakter pemain (dipakai di semua tema) |
| `themes/wedding/shared/` | Benda yang dipakai kedua venue pernikahan |
| `themes/wedding/garden-sunset/` | Venue taman (outdoor) |
| `themes/wedding/grand-ballroom/` | Venue ballroom (indoor) |
| `themes/museum/` | Tema Museum Kenangan (belum dipakai) |
| `themes/birthday/` | Tema Ulang Tahun (rencana) |
| `sky/` | Langit HDRI |
| `textures/` | Tekstur lantai/karpet yang bisa diulang |
| `audio/music/`, `audio/sfx/` | Musik latar dan efek suara |

Ukuran: benda kecil < 500 KB, sedang < 2 MB, karakter < 5 MB, satu file maks 20 MB
(batas Cloudflare 25 MB per file). Kompres GLB dengan Draco atau Meshopt.
