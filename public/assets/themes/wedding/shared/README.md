# Wedding — dipakai kedua venue

Aturan untuk semua file di folder ini:
- Format **.glb**, satuan meter, sumbu Y ke atas, depan model menghadap +Z.
- Origin di lantai, tengah alas benda.
- Gaya stylized / ilustrasi lembut (bukan low-poly kotak). Tekstur maks 1024 px (karakter boleh 2048).
- Nama file persis seperti tabel di bawah.

| File | Ukuran kira-kira | Catatan |
|---|---|---|
| `info-board.glb` | 1,6 × 2,3 m | Papan berdiri — bidang isi **kosong** (MEMORA menulis jadwal acara) |
| `envelope-box.glb` | 0,6 × 1,3 m | Kotak amplop putih-emas di atas meja kecil |
| `wishes-board.glb` | 4,6 × 2,6 m | Papan ucapan — bidang kartu **kosong** |
| `photo-easel.glb` | tinggi 2 m | Standing frame foto |
| `photo-frame-gold.glb` | 1 × 1 m | Bingkai emas — bidang foto **kosong**, rasio 3:4 dan 4:3 |
| `flower-arch.glb` | lebar 4,4 × tinggi 3,6 m | Gapura bunga pintu masuk |
| `flower-stand.glb` | tinggi 1,3 m | Tiang + buket mawar (tepi karpet) |
