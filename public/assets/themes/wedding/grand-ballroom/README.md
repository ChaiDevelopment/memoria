# Grand Ballroom (indoor) — ruangan 32 × 48 m, tinggi 7 m

Aturan untuk semua file di folder ini:
- Format **.glb**, satuan meter, sumbu Y ke atas, depan model menghadap +Z.
- Origin di lantai, tengah alas benda.
- Gaya stylized / ilustrasi lembut (bukan low-poly kotak). Tekstur maks 1024 px (karakter boleh 2048).
- Nama file persis seperti tabel di bawah.

| File | Catatan |
|---|---|
| `ballroom-shell.glb` | Dinding, jendela lengkung, plafon bertingkat — **tanpa** lantai & karpet; sisakan bidang dinding di x = ±15,8 untuk bingkai foto |
| `pillar-classic.glb` | Tinggi 7 m, radius 0,42 m |
| `chandelier-grand.glb` | Lampu kristal besar (bagian lampu emissive) |
| `chandelier-small.glb` | Lampu kristal kecil |
| `curtain-velvet.glb` | Tirai merah marun + pengikat emas |
| `stage-ballroom.glb` | Panggung dua tingkat (0,25 m & 0,5 m), backdrop putih-emas berukir |
| `sofa-wedding.glb` | Sofa pengantin putih-emas |
| `table-round.glb` | Meja bundar r 0,9 m bertaplak |
| `chair-banquet.glb` | Kursi bersarung putih + pita merah |
| `centerpiece-flowers.glb` | Bunga + lilin di tengah meja |
| `flower-pedestal.glb` | Pilar putih + rangkaian bunga |
