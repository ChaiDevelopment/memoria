# Animasi

Animasi untuk rig `character-base.glb` (boleh dari Mixamo, ekspor **without skin**, 30 fps, in-place / tanpa root motion).

| File | Gerakan |
|---|---|
| `idle.glb` | Berdiri santai |
| `walk.glb` | Berjalan |
| `run.glb` | Berlari |
| `jump.glb` | Melompat |
| `sit.glb` | Duduk di kursi setinggi 0,45 m |
| `wave.glb` | Melambai |
| `clap.glb` | Bertepuk tangan |
| `inspect.glb` | Melihat foto, tangan di dagu |
