# Pakaian karakter

Aturan untuk semua file di folder ini:
- Format **.glb**, satuan meter, sumbu Y ke atas, depan model menghadap +Z.
- Origin di lantai, tengah alas benda.
- Gaya stylized / ilustrasi lembut (bukan low-poly kotak). Tekstur maks 1024 px (karakter boleh 2048).
- Nama file persis seperti tabel di bawah.

Mesh terpisah yang menempel di rig `character-base.glb` (bisa ditukar).

| File | Isi |
|---|---|
| `outfit-casual.glb` | Sweater + celana (tamu) |
| `outfit-suit.glb` | Jas hitam, kemeja putih, dasi kupu-kupu (pengantin pria) |
| `outfit-gown.glb` | Gaun pengantin putih mengembang + veil + buket (pengantin wanita) |
| `outfit-hijab.glb` | Gamis + hijab |
| `outfit-kebaya.glb` | Kebaya (opsional) |
